# DRIFT 12.11.1 — scene refinement build

This build goes back to the stable 12.11 base and applies only the requested scene refinements plus a slight slowdown to cloud generation / morphing. Forward travel speed is unchanged.

Changes:
- Slightly slower cloud generation / morphing (not slower forward travel).
- Thunderstorm darker and more ominous, with darker cloud bodies and compressed tonal range for better lightning contrast.
- Dark Cloud has a deeper grey range, greyer backing, more mist/grain, more grey variation, and less visible blue/contour leakage.
- Sunrise uses richer coral/orange/gold with pink-red illumination and cooler violet-blue support colours.
- Sunset clouds inherit more orange/red/pink from the environment, especially around edges.
- No playlist / multi-track system in this build.

Upload the full package to the GitHub Pages repo root and commit.
