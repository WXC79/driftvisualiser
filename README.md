# DRIFT 12.10 — Scene refinement build

This update keeps the 12.9 pacing and Home Screen behaviour, but refines the scene palettes and auto-mode variety.

## Main changes

- Dark Cloud background is now a darker threatening rain-grey.
- Dark Cloud clouds are lighter and more varied in grey values.
- Thunderstorm background is a deeper dark grey with less blue showing through.
- Sunrise is more saturated and more orange.
- Night is more fully night, with less blue-sky leakage.
- Auto mode is more willing to choose Sunrise and Night, so the journey should feel more complete.

## Update GitHub Pages

Replace the files in your repo root with the contents of this package and commit.

The service-worker cache name has been updated so Home Screen installs should pick up the new version more reliably.

## Next planned feature

Once the scenes feel right, the next major feature can be touch-based cloud spawning, where holding a finger on the screen injects density into the cloud field and lets the user grow their own cloud masses.
